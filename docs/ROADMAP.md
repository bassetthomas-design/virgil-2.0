# Virgil 2.0 - Roadmap

## Phase 0 - Initialisation

- Conserver le nom Virgil
- Créer une base projet dédiée `virgil-2.0`
- Reprendre les fondations de Virgil v1
- Ajouter la direction visuelle Tactical HUD orange/noir

## Phase 1 - Base saine

- Restaurer la structure App / Core / Agent / Tests
- Vérifier le calcul RAM
- Ajouter logs propres
- Ajouter sécurité des actions sensibles
- Préparer le scan pilotes avec bouton d'installation après résultats

## Phase 2 - Interface Tactical HUD

- Thème sombre et accent orange
- Notifications internes type agent système
- Effets de scan légers
- Cartes de statut CPU / RAM / disque / réseau
- Avatar avec états : idle, scan, alert, success, error

## Phase 3 - Agent PC

- Surveillance en arrière-plan
- Icône tray
- Alertes système
- Recommandations automatiques
- Mode diagnostic express

## Phase 4 - Packaging

- Build Release x64
- Artefact GitHub Actions
- Script d'installation
- Notes de version
